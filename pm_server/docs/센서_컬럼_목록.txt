예지보전 모델별 입력 컬럼 (POST /predict/... 요청의 readings 한 줄)
기준: pdm/features.py (2026-10-24). 서버 GET /spec 에서도 같은 내용을 볼 수 있어요.

================================================================
[CCTV] CCTV  - 모델: 이 폴더에서 학습 (train.py)
  데이터 간격 1시간 · 최근 14개 (창 12 + 연속 3번 - 1) · 시각 열 이름: collected_at
================================================================
  video_receive_rate   영상 수신률     단위: %
  response_time_ms     응답 시간      단위: ms
  packet_loss_rate     패킷 손실률     단위: %
  image_blur_score     화면 흐림      단위: 점

  특징값 (모델 입력, 서버가 계산):
    receive_mean      영상 수신률 평균
    response_mean     응답 시간 평균
    response_trend    응답 시간 증가 추세
    loss_mean         패킷 손실률 평균
    blur_max          화면 흐림 최대

================================================================
[PUMP] 배수펌프  - 모델: 이 폴더에서 학습 (train.py)
  데이터 간격 10초 · 최근 35개 (창 30 + 연속 6번 - 1) · 시각 열 이름: collected_at
================================================================
※ 이름은 임의로 붙였어요. 원본(펌프 시연 CSV)은 sensor_00~49 처럼 이름이 없고, 값은 원본 숫자 그대로라 단위가 없어요.
※ 종류마다 고장 구간에서 가장 크게 변하는 센서 하나를 골랐어요. 학습 데이터는 1분 원본을 10초로 가공(합성).

  vibration            진동센서       단위: -   원본 sensor_23
  pressure             압력센서       단위: -   원본 sensor_28
  temperature          온도센서       단위: -   원본 sensor_00
  current              전류센서       단위: -   원본 sensor_13
  flow                 유량센서       단위: -   원본 sensor_42
  rpm                  회전수센서      단위: -   원본 sensor_45

  특징값 (모델 입력, 서버가 계산):
    vib_level         진동 이상 정도
    vib_vol           진동 변동성
    press_level       압력 이상 정도
    temp_trend        온도 변화 추세
    out_share         평소 범위를 벗어난 센서 비율

================================================================

  데이터 간격 5분 · 최소 300개, 권장 2~3일 · 시각 열 이름: observed_at
================================================================
  level_m              측정 수위      단위: m

  특징값 (모델 입력, 서버가 계산):
    res_max3          최근 15분 최대 이탈폭
    res_max12         최근 1시간 최대 이탈폭
    res_sd12          최근 1시간 흔들림
    slope_dev         1시간 기울기와 6시간 기울기 차이
    slope24           24시간 기울기

================================================================
[DISPLAY] 전광판  - 모델: 팀원 최종 모델 그대로 (pm_final)
  데이터 간격 1시간 · 최소 24개, 권장 72시간 + 평소 값(baseline) · 시각 열 이름: collected_at
================================================================
  temperature_c        본체 온도      단위: ℃
  ambient_c            외기 온도      단위: ℃
  ripple_v             전원 리플      단위: V
  response_time_ms     응답 시간      단위: ms
  error_count          오류 횟수      단위: 건
  bad_pixel_pct        불량 화소 비율   단위: %

  특징값 (모델 입력, 서버가 계산):
    temp_gap          본체-외기 온도차
    ripple_v          전원 리플
    response_time_ms  응답 시간
    error_count       오류 횟수
    bad_pixel_pct     불량 화소 비율
