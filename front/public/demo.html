① 지하차도 위험 5단계 (고정) — 관리자 로그인 필요

버튼을 누르면 실제 침수모델·수위계처럼 위험점수와 수위 값을 넣고 그 단계로 고정합니다. 단계 판정 → 알림·전광판·내비 우회·자동 통제는 원래 로직이 그대로 합니다. 안전 5점 · 관심/주의는 점수 · 경계/심각은 수위(통제 수위 이상) → 경계부터 자동 통제.

고정된 지하차도는 실제 침수 서버 점수·예측, 호우 시나리오, 평상시 가짜 갱신이 덮어쓰지 않습니다. 고정 값은 10초마다 다시 들어갑니다. 풀면 실제 침수 서버가 다시 이어받습니다.

② 호우 시나리오 (날씨 악화부터 자동 진행 · 실제 침수 서버가 계산)
