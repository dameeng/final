- 실제 주소 조회 결과·마커 위치 조정 후 서버 저장
- 실제 CCTV·기상청·OCR·예측·센서 수신
- 문자·푸시·도로 통제·전광판·경찰·소방 실제 전송
- 실제 경로 계산·위험 회피·내비게이션
