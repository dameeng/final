ROUTEL 고객 앱·관리자 앱 PWA

두 앱의 화면, 설치 아이콘, 매니페스트와 오프라인 기본 화면을 포함한 정적 배포 파일입니다. APK 파일이 아닙니다.

1. 휴대폰 설치용으로 배포

  1. ZIP 압축을 풉니다.
  2. site 폴더의 내용을 HTTPS 정적 호스팅 사이트의 루트에 업로드합니다. Netlify 수동 배포를 사용할 경우 site 폴더를 업로드할 수 있습니다. 다른 호스팅은 존재하지 않는 앱 경로를 index.html로 연결하는 SPA 설정이 필요합니다.
  3. 배포된 주소의 /pwa/를 휴대폰에서 엽니다.
  4. 고객 앱 또는 관리자 앱을 선택합니다.
  5. 안드로이드 Chrome: 메뉴 → 앱 설치 / 홈 화면에 추가. 아이폰 Safari: 공유 → 홈 화면에 추가.

예시: https://배포주소/pwa/

2. 로그인 없이 확인

설치 안내 화면에서 ‘로그인 없이 둘러보기’를 선택하세요. 별도 계정을 생성하거나 로그인하지 않으며, 표시된 시설 상태·수치는 구성 예시입니다. 실제 통제·회원정보·날씨 API는 백엔드 연결 후 사용할 수 있습니다.

3. PC에서 바로 실행

Node.js가 설치된 PC에서 압축을 푼 폴더의 터미널을 열고 node serve.mjs를 실행한 뒤 http://localhost:8283/pwa/를 여세요. 같은 와이파이의 휴대폰에서는 PC의 내부 IP와 포트 8283으로 화면 미리보기가 가능합니다. PC 방화벽이 연결을 허용해야 합니다. 휴대폰의 일반 HTTP 접속은 PWA 설치용이 아니며, 실제 설치에는 HTTPS 배포 주소를 사용하세요.

4. 서버·지도 연결

이 파일에는 백엔드 서버와 DB가 들어 있지 않습니다. 실제 로그인·날씨·통제 기능을 사용하려면 동일한 사이트의 /api 요청을 백엔드로 전달하도록 설정해야 합니다. 공개 정적 호스팅으로만 배포하면 로그인 서비스는 동작하지 않습니다.

카카오 지도를 사용할 경우 배포 주소를 카카오 개발자 콘솔의 JavaScript 허용 도메인에 등록하세요. 이 빌드는 프로젝트에 설정된 공개 프런트 환경값을 반영합니다. 서버 인증키는 프런트에 추가하지 마세요.

5. 오프라인과 업데이트

첫 접속에서 내려받은 앱 기본 파일은 오프라인에서도 열 수 있습니다. 실시간 지도·날씨·영상·계정 조회는 네트워크가 필요하며 API 응답은 오프라인 캐시에 저장하지 않습니다. 오프라인에서는 표시된 상태를 현재 도로 상황으로 사용하지 마세요. 새 버전은 앱을 완전히 닫고 다시 열 때 적용됩니다.
