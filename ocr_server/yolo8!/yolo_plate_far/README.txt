번호판 위치 찾기 모델 (YOLOv8n, 먼 거리 보강판)
=================================================

■ 사용법
  1) pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118
  2) pip install -r requirements.txt
  3) python -u predict.py <사진 폴더 또는 사진>
     → 사진마다 찾은 번호판 네모가 화면에 나오고, 네모 그린 사진은 result 폴더에 저장

■ 꼭 지킬 것
  - 사용할 때 imgsz=1280 을 꼭 넣기 (기본값 640이면 먼 번호판을 더 놓침)
      model = YOLO("best.pt")
      model.predict("사진.jpg", imgsz=1280)
  - 클래스는 1개: license_plate

■ 학습 내용
  - 출발점: best8.pt (가까운 번호판 538장으로 학습한 모델)
  - 학습 사진 2,038장 = 원본 538장 + 먼 거리 연습 사진 1,500장
    (원본 사진 4/9/16장을 작게 줄여 바둑판처럼 붙인 사진, make_far_dataset.py)
  - imgsz 1280, 30바퀴(epoch), batch 8, scale 0.9, RTX 3060에서 약 26분
  - 날짜: 2026-09-24

■ 성능 (R = 번호판을 찾은 비율)
  먼 거리 시험지 150장 (번호판 1,406개)
    모델           크기    R       mAP50
    예전 best8     640    19.3%   22.0%
    예전 best8     1280   91.3%   96.4%
    이 모델        640    96.2%   98.2%
    이 모델        1280   99.9%   99.5%   ← 추천

  원래 검증 59장 (가까운 번호판)
    예전 best8     640    99.8%   99.5%
    예전 best8     1280   89.8%   95.4%
    이 모델        1280   100%    99.5%

■ 주의
  먼 거리 시험지는 사진을 줄여서 만든 흉내라, 실제 카메라의 먼 번호판은 더 흐릴 수 있음.
  실제 사진으로 한 번 확인하고 쓰기.
