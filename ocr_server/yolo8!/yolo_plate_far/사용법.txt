번호판 위치 찾기 모델 — 쓰는 법
================================
(Windows 파워셸 기준. 명령어는 한 줄씩 복사해서 붙여 넣고 엔터)


1. 폴더 안에 있는 것
--------------------
  best.pt            모델 파일. 이것만 있으면 모델은 끝
  predict.py         사진/폴더/동영상을 넣으면 번호판을 찾아 주는 코드
  requirements.txt   설치할 프로그램 목록
  README.txt         학습 내용과 성능 표
  사용법.txt         지금 이 파일


2. 처음 한 번만: 설치하기
------------------------
  준비물: 파이썬 3.10 ~ 3.13, (있으면) NVIDIA 그래픽카드

  (1) zip을 푼 폴더로 가기
      cd C:\어딘가\yolo_plate_far

  (2) 이 폴더 전용 가상환경 만들기 (다른 프로그램과 안 섞이게)
      python -m venv venv

  (3) 가상환경 켜기
      .\venv\Scripts\Activate.ps1
      → 앞에 (venv)가 붙으면 성공
      → "스크립트를 실행할 수 없습니다" 에러가 나면 아래 줄을 먼저 치고 다시:
        Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

  (4) torch 설치 (둘 중 하나만)
      그래픽카드 있음: pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118
      그래픽카드 없음: pip install torch==2.7.1
      (그래픽카드 없어도 돌아가지만 느려요)

  (5) YOLO 설치
      pip install -r requirements.txt

  (6) 잘 깔렸는지 확인
      python -c "import torch, ultralytics; print(ultralytics.__version__, torch.cuda.is_available())"
      → 8.4.153 True  : 그래픽카드로 돌아요
      → 8.4.153 False : CPU로 돌아요 (느리지만 됨)


3. 쓰기
-------
  (가상환경이 켜져 있어야 해요. 새 창이면 2-(3)부터)

  사진 폴더:   python -u predict.py C:\사진폴더
  사진 한 장:  python -u predict.py C:\사진폴더\car.jpg
  동영상:      python -u predict.py C:\영상\cctv.mp4

  화면에 이렇게 나와요:
      car.jpg 번호판 2개 [[1004, 808, 1260, 874], [221, 971, 262, 981]]
      → 네모 하나 = [왼쪽 x, 위쪽 y, 오른쪽 x, 아래쪽 y]  (원본 사진의 픽셀 위치)
      → 번호판 0개 = 못 찾음

  네모를 그린 사진(동영상)은 이 폴더 안 result 폴더에 저장돼요.
  다시 돌리면 같은 이름은 덮어써요.

5. 내 코드에서 쓰기
-------------------
  from ultralytics import YOLO
  import cv2

  model = YOLO("best.pt")                                   # 모델 불러오기
  img = cv2.imread("car.jpg")                               # 사진 읽기
  r = model.predict(img, imgsz=1280, conf=0.25, verbose=False)[0]   # ★ imgsz=1280 꼭
  for n, (x1, y1, x2, y2) in enumerate(r.boxes.xyxy.int().tolist()):
      plate = img[y1:y2, x1:x2]                             # 번호판 부분만 잘라내기
      cv2.imwrite(f"plate_{n}.jpg", plate)                  # → 이걸 OCR(글자 읽기)에 넘기면 돼요
      print("자신감", float(r.boxes.conf[n]))               # 0~1, 높을수록 확실

  ※ 한글 경로의 사진은 cv2.imread가 못 읽어요. 그럴 땐:
      import numpy as np
      img = cv2.imdecode(np.fromfile("사진.jpg", np.uint8), cv2.IMREAD_COLOR)


6. 설정 바꾸기 (predict.py 7번째 줄)
------------------------------------
  imgsz=1280   바꾸지 마세요. 640으로 줄이면 먼 번호판을 더 놓쳐요 (99.9% → 96.2%)
  conf=0.25    이 자신감보다 낮은 네모는 버려요
               - 번호판을 자꾸 놓치면 → 0.15 처럼 낮추기
               - 엉뚱한 곳을 번호판이라고 하면 → 0.4 처럼 올리기
  CPU로 강제로 돌리고 싶으면 괄호 안에 device="cpu" 추가


7. 자주 나는 문제
-----------------
  No module named 'ultralytics'
      → 가상환경이 안 켜졌어요. 2-(3) 다시

  torch.cuda.is_available() 가 False (그래픽카드가 있는데)
      → CPU용 torch가 깔렸어요:
        pip uninstall -y torch
        pip install torch==2.7.1 --index-url https://download.pytorch.org/whl/cu118

  CUDA out of memory
      → 그래픽카드 메모리 부족. 다른 프로그램을 끄거나 device="cpu"

  번호판을 못 찾아요
      → imgsz=1280이 들어갔는지 먼저 확인
      → conf를 0.15로 낮춰 보기
      → 그래도 안 되면 그 사진을 모아 두세요 (다음 학습 재료)
