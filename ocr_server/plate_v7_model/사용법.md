# 번호판 읽기 모듈 (PaddleOCR v7)

YOLOv8로 찾은 번호판 네모를 넣으면 번호를 읽어주는 모듈이에요.
번호판 **위치 찾기(YOLOv8)는 들어있지 않아요.** 팀에서 쓰는 YOLOv8 모델을 그대로 쓰면 돼요.

## 들어있는 것

| 경로 | 내용 |
|---|---|
| `plate_reader.py` | 번호판 사진 → 번호 읽기 (이것만 import하면 돼요) |
| `models/rec_v7/` | 번호 읽는 모델 (v7) |
| `models/det/` | 번호판 안에서 글자 줄 찾는 모델 (PP-OCRv5_server_det) |
| `models/base_rec/` | 자르기 후보 고르는 기본 한글 모델 (korean_PP-OCRv5_mobile_rec) |
| `dict/` | 두 읽기 모델의 글자 사전 |
| `paddleocr_lib/` | 모델을 돌리는 PaddleOCR 코드 (건드리지 마세요) |

## 설치

```bash
pip install -r requirements.txt
```

- Python 3.13, Windows, RTX 3060에서 확인했어요.

## 기본 사용

```python
import cv2
from plate_reader import PlateReader, crop_box

reader = PlateReader()                              # 모델 3개 켜기 (약 2.5초, 한 번만)
frame = cv2.imread("car.jpg")
x0, y0, x1, y1 = ...                                # YOLOv8이 찾은 번호판 네모
text, conf, ok = reader.read(crop_box(frame, [x0, y0, x1, y1]))
print(text, conf, ok)                               # 예: 12가3456 0.97 True
```

- `crop_box` : YOLO 네모 둘레에 여백 15%를 붙여 잘라요. **꼭 이걸로 자르세요.** 테스트할 때와 똑같은 방식이에요.
- `text` : 읽은 번호 (못 읽으면 빈 글자 `""`)
- `conf` : 자신감 0~1
- `ok` : 믿어도 되는지. 번호판 규칙에 맞고 자신감이 0.88 이상이면 `True`예요. **화면에 보여줄 때는 `ok`가 `True`인 것만 쓰는 걸 추천해요.**

## FastAPI 예시

```python
import numpy as np, cv2
from fastapi import FastAPI, UploadFile
from ultralytics import YOLO
from plate_reader import PlateReader, crop_box

app = FastAPI()
yolo = YOLO("best8.pt")                             # 팀 YOLOv8 모델
reader = PlateReader()                              # 서버 켤 때 한 번만 만들기 (요청마다 만들면 느려요)

@app.post("/plate")
async def plate(file: UploadFile):
    img = cv2.imdecode(np.frombuffer(await file.read(), np.uint8), cv2.IMREAD_COLOR)
    result = []
    for b in yolo.predict(img, imgsz=1280, conf=0.25, verbose=False)[0].boxes:
        box = [int(v) for v in b.xyxy[0].tolist()]
        text, conf, ok = reader.read(crop_box(img, box))
        result.append({"box": box, "text": text, "conf": round(conf, 3), "ok": ok})
    return {"plates": result}
```

```bash
uvicorn main:app --reload
```
- `PlateReader`는 명령어 줄을 읽지 않아서 `uvicorn`과 같이 써도 괜찮아요.
- 테스트할 때는 YOLO `imgsz=1280`, `conf=0.25`를 썼어요.

## 성능 (기말고사 1,952장, v6와 비교)

| 사진 종류 | v6 | v7 |
|---|---|---|
| 깨끗하게 자른 사진 (순수 읽기 실력) | 94.77% | **95.59%** |
| 자동으로 자른 사진 (실전) | 93.75% | **94.36%** |

- 속도: 번호판 1개당 약 75ms (RTX 3060)
- 약점: 받침 없는 비슷한 글자(**오↔모, 어↔머, 무↔우**)를 가끔 헷갈려요. 이럴 때는 보통 자신감이 낮아서 `ok=False`로 걸러져요.
